# Étape 3 — Compartiments par diagnostic

> Repris mot pour mot (section VIII). Le tableau de décision opérationnel est dans `3-decision.md`.

▸ TROUBLE DE L'ADAPTATION SEUL NOTE — pas de rubrique « sur le plan chronique ». La rupture avec le fonctionnement habituel est portée par le plan aigu, dans la délimitation et le facteur de crise. STATUS — cohérent avec la crise. Un status entièrement neutre est ici une faute. DIAGNOSTIC — sous-type examiné et retenu si le tableau le porte. SYNTHÈSE — branche 2 ou
3. Argumentation : symptomatologie + rupture + facteur + retentissement. NE PAS ÉCRIRE — traits de personnalité, éléments chroniques, différentiel non argumenté.

▸ CODE Z OU DIFFICULTÉ CIRCONSCRITE NOTE — plan chronique branche A. STATUS — sans particularité en dehors de ce que le contexte explique. SYNTHÈSE — branche
5. Évolution branche
6. NE PAS ÉCRIRE — symptomatologie généralisée, éléments suggérant un trouble constitué.

▸ TROUBLE DE L'ADAPTATION AVEC ACCENTUATION DE TRAITS NOTE — plan chronique branche B, développé, sans nommer le registre. STATUS — ce qui a été réellement observé et va dans ce sens. SYNTHÈSE — branche 2 ou 3, puis supplémentaire branche 2 avec le registre nommé. Évolution branche
2. Issue fondée sur les difficultés persistantes. NE PAS ÉCRIRE — traits décrits sans être nommés en synthèse ; traits nommés sans manifestation, ancienneté ni sphères.

▸ TROUBLE DE LA PERSONNALITÉ RETENU NOTE — plan chronique branche B, développé, portant les critères. Sans poser le diagnostic ici. STATUS — cohérent avec ce qui est retenu. SYNTHÈSE — paragraphe diagnostique branche 4 si principal, supplémentaire branche 3 si second. Formulation du fonctionnement, jamais reprise du plan chronique. Évolution branche
2. NE PAS ÉCRIRE — un diagnostic posé sur le seul matériel de crise ; une argumentation qui réénumère les manifestations de la note.

▸ HYPOTHÈSE NEURODÉVELOPPEMENTALE NOTE — plan chronique branche C, uniquement les plaintes formulées. Le commentaire sur l'exploration va dans la rubrique Hypothèses. STATUS — pas de signes orientant vers ce diagnostic s'ils n'ont pas été observés. SYNTHÈSE — supplémentaire branche 4 si écartée, branche 5 si poursuivie. NE PAS ÉCRIRE — un dépistage positif présenté comme un diagnostic ; des critères construits à partir de questions guidées.

▸ SITUATION NON CONCLUSIVE OU INTERROMPUE NOTE — plan chronique seulement si des éléments durables existent réellement. SYNTHÈSE — diagnostique branche 6 ou 7, cadre en branche interruption, évolution branche 7, issue branche
6. RÈGLE TRANSVERSALE DU STATUS — il ne contient jamais d'élément orientant vers un diagnostic non retenu, et contient ce que le diagnostic retenu implique.
